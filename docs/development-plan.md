## 技术栈总结

## 风险与应对

| 风险 | 应对措施 |
|------|---------|
| Electron 安全问题 | 禁用 Node.js 集成，使用预加载脚本 |
| SQLite 并发问题 | 使用单一连接，主进程统一管理 |
| Excel 格式兼容性 | 提供模板下载，严格格式验证 |
| 大量节点渲染性能 | 虚拟滚动、分页加载 |
| 数据库文件损坏 | 提供数据库重建选项 |
