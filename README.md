# ChoubeiPlanner - 商业地产项目筹备计划生成系统

## 项目概述

ChoubeiPlanner 是一个轻量级 Web 应用，用于商业地产项目经理生成和管理项目筹备计划。系统根据用户设定的基石时间点和预定义规则，自动生成项目时间计划，并检测潜在的时序冲突。

## 五、核心引擎模块

### 5.1 计划生成器 (planGenerator.ts)

**功能**: 根据基石时间点和规则生成节点计划

**输入**:
- `cornerstoneData`: 基石时间点映射
- `rules`: 规则列表

**输出**: 节点列表

**计算逻辑**:
```
开始日期 = 基准点日期 + 偏移天数
结束日期 = 开始日期 + 节点时长
```

### 5.2 冲突检测器 (conflictDetector.ts)

**功能**: 检测节点间的时序冲突

**检测类型**:
1. **前置依赖冲突** (error): 节点A必须在节点B完成后开始，但A开始时间 < B结束时间
2. **must_before冲突** (warning): 节点A必须在节点B之前完成，但A结束时间 >= B开始时间
3. **验收标准冲突** (warning): 验收截止时间 > 节点结束时间

### 5.3 规则评估器 (ruleEvaluator.ts)

**功能**: 验证规则的有效性

**验证项**:
- 必填字段检查
- 基准点有效性
- 偏移量和时长数值验证
- 循环依赖检测

## 六、用户使用指南

### 6.1 快速开始

#### 步骤1: 导入规则
1. 访问"规则管理"页面
2. 点击"下载模板"获取规则Excel模板
3. 填写规则后点击"导入规则"上传
4. 点击"验证规则"确保规则正确

#### 步骤2: 创建项目
1. 返回"项目列表"页面
2. 点击"新建项目"按钮
3. 填写项目名称、描述
4. 设置四个基石时间点 (必须按时间顺序):
   - 项目签约
   - 动工
   - 竣工备案
   - 开业
5. 点击"创建"

#### 步骤3: 生成计划
1. 进入项目编辑页面
2. 点击"重新生成计划"
3. 系统自动根据规则生成节点
4. 查看时间轴或列表视图

#### 步骤4: 调整节点
1. 点击节点进入编辑
2. 修改日期、验收标准等
3. 系统自动检测冲突
4. 查看底部冲突警告

#### 步骤5: 导出计划
1. 点击"导出"按钮
2. 下载Excel文件 (包含项目信息、节点列表、冲突报告)

### 6.2 规则Excel格式

| 列名 | 说明 | 示例 |
|-----|------|------|
| 节点名称 | 任务名称 | 方案设计 |
| 节点分级 | 优先级 | 1 |
| 涉及专业 | 负责专业 | 设计 |
| 基准点 | 参照的基石时间 | 项目签约 |
| 偏移天数 | 相对基准点的偏移 | 0 |
| 节点时长 | 持续天数 | 30 |
| 依赖节点 | 前置任务(逗号分隔) | 施工图设计 |
| 验收标准 | 验收项(逗号分隔) | 我方交付,业主验收 |

### 6.3 冲突说明

| 严重程度 | 图标 | 说明 | 处理建议 |
|---------|------|------|---------|
| 错误 (红色) | ✕ | 必须修复的问题 | 调整节点时间或依赖关系 |
| 警告 (黄色) | ⚠ | 建议关注的问题 | 可选择忽略或调整 |

## 八、常见问题

### Q1: 点击按钮没有反应?
检查浏览器控制台是否有错误，确保后端服务正在运行。

### Q2: 生成计划失败?
确保已导入规则，且规则验证通过。检查基石时间点是否填写完整。

### Q3: 如何修改已有项目的基石时间?
目前需要删除项目重新创建，后续版本会支持编辑。

### Q4: 导出的Excel文件格式?
包含三个工作表:
- 项目信息: 基本信息和基石时间
- 节点列表: 所有节点详情
- 冲突报告: 检测到的冲突
